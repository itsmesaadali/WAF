WAF Link Guard demo

A pretend inbox with links people might send you. With the extension installed, dangerous links get a red dashed outline, and clicking one shows a warning first. If you click Open anyway, the Hybrid WAF blocks the request too: two layers of defence.

Safe links

  • Search for books
  • Product 2
  • A search with an apostrophe (O'Brien mug)
  • Contact page

Booby-trapped links

  • "Check out this discount!" steals cookies with a script tag
  • "Your order status" SQL injection that dumps passwords
  • "Free gift card" double-encoded XSS
  • "See the photo" attack in the #fragment, which never reaches the server or the WAF
  • "Track your parcel" base64-hidden SQL injection
